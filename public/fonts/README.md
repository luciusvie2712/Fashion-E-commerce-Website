# Vietnamese serif typography

Gelasio provides complete Vietnamese glyph coverage while retaining Georgia-compatible metrics and a similar editorial serif appearance. It is used for the entire Vietnamese interface so accented and unaccented characters share the same face. Other locales retain the system Georgia stack and local CJK fallbacks. Controls and toast messages inherit the selected face.

- Source: https://github.com/google/fonts/tree/a60a77e14f28abd4ef243a1b5dfc48df0cec5205/ofl/gelasio
- Typeface project: https://github.com/SorkinType/Gelasio
- Original filenames: `Gelasio[wght].ttf`, `Gelasio-Italic[wght].ttf`.
- Local files: `Gelasio-Variable.ttf`, `Gelasio-Italic-Variable.ttf`, unchanged variable fonts, weights 400–700.
- License: SIL Open Font License 1.1, included in `OFL-Gelasio.txt`.

Both fonts are served from this project. There is no Google Fonts stylesheet or external runtime font request. No proprietary Georgia font file is redistributed.
